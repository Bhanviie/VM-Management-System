# VM Management System

## Project Overview
The VM Management System is a web-based application designed to manage and monitor virtual machines through a user-friendly dashboard.

## Technologies Used
- Python
- Flask
- HTML
- CSS
- JavaScript
- VirtualBox
- VBoxManage

## Key Features
- User authentication and login
- Create and manage virtual machines
- Start and shut down virtual machines
- Monitor virtual machine status
- Dashboard for VM management
- Activity logging

## Project Objective
To simplify virtual machine management by providing a centralized web interface for performing and monitoring VM operations.

## Repository
This repository contains the source code for the VM Management System.
